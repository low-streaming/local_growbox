# 🇬🇧 English
**Release v2.1.4 - Humidifier Support & Repository Migration 🚀**

We are excited to release the latest update for the Local Grow Box integration! First things first: We have moved! You can now find the project under its new home on GitHub: **`openkairo/GrowRoom_Local`**.

**What's new in v2.1.4:**
- **💧 Humidifier Support:** You can now configure an optional humidifier entity alongside your exhaust fan. The smart climate automation will automatically control the humidifier to maintain the minimum required humidity level based on your targeted growth phase.
- **🔄 Repository Migration (`openkairo`):** All README links, HACS paths, and internal API references have been updated to reflect the new `openkairo/GrowRoom_Local` repository.
- **🛠️ Bugfixes & Reliability:** Minor under-the-hood tweaks to ensure an even smoother and stable operation.

*Happy Growing! 🌿*
