# 🇬🇧 English
**Release v2.1.6 - Dashboard Stability & Enhanced Help 🛡️**

This update focuses on long-term dashboard stability and improved user guidance.

**What's new in v2.1.6:**
- **🛡️ Dashboard Stability Fix:** Resolved an issue where the dashboard panel could "disappear" after being open for a long period. The rendering logic has been optimized to prevent unnecessary background updates.
- **⚡ Performance Boost:** Static tabs (Info, Settings) now consume significantly fewer resources as they no longer re-render on every sensor update.
- **📖 Enhanced Help Page:** The Help & Info page has been completely restructured, featuring detailed explanations of **Smart Humidification** (pulse logic) and the new control elements.
- **🎨 UI Refinements:** The help page now uses a modern 2-column layout and improved icons for better navigation.

*Happy Growing! 🌿*
